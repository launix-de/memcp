# JIT Branch — Developer Notes

## CRITICAL: Never manually edit generated code

**DO NOT** manually edit JIT emitter closures in `scm/alu.go`, `scm/list.go`,
`scm/strings.go`, or any `storage/storage-*.go` file. These are generated by
`tools/jitgen/main.go`. Run `make jitgen` to regenerate.

To fix JIT emitter bugs, edit **only**:
- `tools/jitgen/main.go` — the code generator
- `scm/jit.go` — the JIT runtime (JITContext, register allocator, AllocStack)
- `scm/jit_amd64.go` — AMD64 machine code emission + Scheme expression compiler

Then run `make jitgen` to regenerate all emitters.

## Architecture

### JIT emitters are inliners

Every `decl.JITEmit(ctx, ...)` call emits machine code directly into the
caller's code buffer. There is NO separate call frame per emitter. All emitters
share the single unified frame owned by `jitCompileProcToExec`.

### Unified stack frame

```
RBP → saved RBP          (push rbp; mov rbp, rsp)
      sub rsp, MaxBPOffset  (patched at the end)
RSP → bottom of frame

Frame layout (RSP-relative, positive offsets):
  [RSP+0 .. localVarsSize)     local variables (Scmer pairs)
  [RSP+localVarsSize .. +phi)  phi slots (allocated by emitters)
  [RSP+phi .. +spill)          spill slots (TODO: move from heap SpillBuf)
```

### AllocStack / FreeStack

Emitters manage their phi-slot space via:
```go
base := ctx.AllocStack(phiSize)  // push: reserves phiSize bytes, returns start offset
// ... use [RSP + base + localOff] for phi slots ...
ctx.FreeStack(phiSize)           // pop: releases for reuse by next emitter
```

`ctx.MaxBPOffset` tracks the high-water-mark. The prolog's `SUB RSP` is patched
with this value at the end. Epilog: `leave; ret`.

### Register protection pattern

When loading two operands for a BinOp (e.g. `a * b`), the first operand's
register must be protected while the second is loaded:
```go
ctx.EnsureDesc(&x)
ctx.ProtectReg(x.Reg)    // prevent eviction
ctx.EnsureDesc(&y)        // may allocate registers
ctx.UnprotectReg(x.Reg)
// now both x and y are in registers
```

## Workflow

```bash
# 1. Edit tools/jitgen/main.go (or scm/jit.go, scm/jit_amd64.go)
# 2. Regenerate all emitters:
make jitgen
# 3. Build:
go build -o memcp
# 4. Test:
./memcp -data /tmp/test --api-port=4498 --no-repl lib/main.scm
```
